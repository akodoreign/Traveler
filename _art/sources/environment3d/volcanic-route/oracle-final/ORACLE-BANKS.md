# Oracle rock banks and lava crossing

M442 uses cleaved, indigo rock and irregular basalt columns behind the old switchback. The native walking test reached the east stair at x51.00, y3.90, z9.50. M443 has a recessed asymmetric lava pool, fitted crust, and vermilion shrine trim. M896 has individually fitted cut stone pavers on the original dry battle grade. In the real M001 group 153 fight, the native ground test found solid support at 116 points and the battle actor walked across to x35.42. The E559 champion and live lava animation loaded.

The original collision, map links, story pages, and champion encounter stayed in place. The three maps select local lighting presets so other maps keep their own lighting. M442 keeps a dawn-story state as well as a separate daylight review. Daylight and story captures in the previews folder are native 3840 by 2160.

The source dependency is the earlier layered-basalt bundle, kept in the work folder alongside the final builder. In the original work folder, run the builder with the repository path, then with --stage and the playtest profile. Run oracle_lighting.py stage on the same profile before native review. The install promotion verifies the live originals and the tested art, settings and map data before writing the three map entries.
