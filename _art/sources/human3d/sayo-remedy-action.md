# Sayo mixes remedies

Sayo holds a bowl in one hand and grinds the selected remedy with a small wooden pestle. Steam rises from the bowl, and she presents the mixture before the original cast runs. Fire remedies tint the steam toward ember. The same preparation plays for manual ingredient recipes and Random Mix. Ume-baa's Poultice also uses the preparation. Diagnosis remains a physical exam in the existing system.

Random Mix appears in Sayo's School menu. It picks once from learned recipes with available ingredients and an affordable skill cost. It returns the original skill before the battle UI opens target selection. The user still aims the selected remedy using that recipe's real targeting rules. Existing ingredient spending at execution and empty-bag handling are unchanged. The menu keeps every manual recipe. Without a craftable ingredient recipe, the optional Random Mix row is disabled.
